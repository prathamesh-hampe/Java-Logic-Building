# Q13 - Zero Digit Counter 🧮

## Problem Statement

A digital audit system monitors how many times digit `0` appears in a number for formatting analysis.

Your task is to count the number of zero digits present.

### Rules

- Consider the absolute value for negative numbers.
- If the input is `0`, the output should be `1` (since it contains one zero).

## Input

An integer `num`

## Output

Display `Count of Zero Digits: X`, where `X` is the count of zero digits.

## Examples

|   Input  |          Output           |
|----------|---------------------------|
|  102030  |  Count of Zero Digits: 3  |
|    0     |  Count of Zero Digits: 1  |
|  -5004   |  Count of Zero Digits: 2  |
