# Q14 - Largest Digit Finder 📊

## Problem Statement

A smart configuration analyzer needs to determine the largest digit present in a number.

You must extract and return the largest single digit (0–9) in the given integer.

### Rules

- Ignore the sign for negative numbers.
- If the input is a single digit, return that digit.

## Input

An integer `num`

## Output

Display `Largest Digit: X`, where `X` is the largest digit.

## Examples

| Input  |       Output       |
|--------|--------------------|
|  5729  |  Largest Digit: 9  |
|  1111  |  Largest Digit: 1  |
|  -804  |  Largest Digit: 8  |
