# Q10 - Warehouse Batch Priority Assignment 📦

## Problem Statement

A warehouse system assigns high priority to batches whose batch number is divisible by 10.

- If the batch number is divisible by 10, display `Priority Batch`.
- Otherwise, display `Normal Batch`.

## Input

An integer `batchNumber`

## Output

Display `Priority Batch` or `Normal Batch`.

## Examples

|  Input  |      Output      |
|---------|------------------|
|  `100`  | `Priority Batch` |
|  `57`   |  `Normal Batch`  |
