# Q15 - Identical Digit Validator 🔐

## Problem Statement

A number validation system checks whether all digits in a number are identical.

A number is considered `Valid` if every digit is the same.

## Examples

| Input |   Output  |
|-------|-----------|
| 7777  |  Valid    |
|  222  |  Valid    |
|  121  | Not Valid |

### Rules

- Single-digit numbers are considered `Valid`.
- Negative numbers are considered `Not Valid`.

## Input

An integer number

## Output

Display `Valid` or `Not Valid`.
