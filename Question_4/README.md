# Q4 - Billing Machine – Ends With 5 Verification 🧾

## Problem Statement

An automated billing system applies a special cashback offer if the invoice number ends with digit `5`.

Your task is to determine whether the entered number ends with `5`.

If true:

```text
Ends With 5

Otherwise:
Does Not End With 5

The program must correctly handle negative numbers as well.

Input
An integer invoiceNumber

Output
Ends With 5 or Does Not End With 5

Examples

| # | Input	| Output              |
|---|----------|---------------------|
| 1 | 145	| Ends With 5         |
| 2 | 32	| Does Not End With 5 |
| 3 | -75	| Ends With 5         |
