# Q2 - Digital Lock – Even Number Authentication 🔐

## Problem Statement

A smart digital lock is programmed to grant access only when an even number is entered.

When a user inputs a number:

- If the number is even → display `Access Granted`
- If the number is odd → display `Access Denied`

The system must work correctly for both positive and negative integers.

## Input

An integer `num`

## Output

`Access Granted` or `Access Denied`

## Examples

| Input | Output           |
|-------|------------------|
| `24`  | `Access Granted` |
| `13`  | `Access Denied`  |
| `-8`  | `Access Granted` |
