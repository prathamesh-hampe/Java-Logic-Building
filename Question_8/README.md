# Q8 - Last Digit Parity Checker 🔎

## Problem Statement

A numeric analyzer checks whether the last digit of a number is even or odd.

Output:

- `Last Digit Even`
- `Last Digit Odd`

## Input

An integer `num`

## Output

Display the appropriate parity message.

## Example

| # | Input |      Output       |
|---|-------|-------------------|
| 1 |  78   |  Last Digit Even  |
| 2 |  93   |  Last Digit Odd   |
